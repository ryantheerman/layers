# Layers

A browser-based diagramming tool with semantic zoom. Instead of optical zoom, navigating into a node reveals its children as the new scene — letting you move fluidly between abstraction levels in a single diagram.

## Stack

- React 18 + TypeScript + Vite
- Konva + react-konva (canvas rendering)
- Rough.js (hand-drawn aesthetic)
- Zustand (state management)

## Dev

```bash
npm install
npm run dev
```
